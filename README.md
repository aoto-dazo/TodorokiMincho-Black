# 轟明朝 Black（Todoroki Mincho Black）

源ノ明朝 JP Heavy（Source Han Serif JP Heavy）を元に、縦画を中心に太らせた極太明朝体です。画数の多い字ほど太らせる量を控え、字の内側の白（フトコロ）が潰れにくいよう調整しています。

- 収録文字数：16,728 字（源ノ明朝 JP と同じ）
- JIS 第1〜第4水準の漢字、かな、英数字、記号などを収録
- 縦書き用の字形も収録

## インストール

`TodorokiMincho-Black.otf` をダブルクリックしてインストールしてください。アプリ上の表示名は「轟明朝 Black」または「Todoroki Mincho Black」です。

## 注意

機械処理で太らせているため、ごく一部の珍しい字（例：龡）は控えめな太さになっています。
